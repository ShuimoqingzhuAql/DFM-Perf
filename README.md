# DFM 画质工坊

《三角洲行动》国服的画质和帧率配置工具，以 LSPosed 模块的形式工作，不需要 root。

装好模块，在 LSPosed 里勾上三角洲行动，打开 App 选档位保存，重启游戏就生效了。

## 能做什么

- 画质六档：流畅、标准、精致、高清、极致、终极
- 帧率六档：60、90、120、144、165、185
- 自定义渲染比例（默认关闭）：0–100%，带 100 / 90 / 80 / 70 四个预设
- 恢复默认：删掉工具写入的画质、帧率、渲染覆盖项
- 保存完之后可以直接启动游戏
- 自检：确认模块能读到本页保存的设置
- 隐藏桌面图标：隐藏后桌面不显示，但仍可从 LSPosed 模块页右下角的圆按钮进入
- 深色模式跟着系统走

## 安装

1. 安装 `DFM-Perf-v1.0.apk`
2. 在 LSPosed 里启用这个模块，作用域只勾“三角洲行动”（`com.tencent.tmgp.dfm`）
3. 打开 App 选好档位，点“保存并下次启动生效”
4. 把游戏完全退掉（最近任务划掉），再重新启动
5. 想看结果就翻 LSPosed 日志，标签 `DFMPerf`

游戏里改动画质或者帧率只影响这一次，重启游戏后会回到 App 里保存的档位。

## 从源码构建

需要 JDK 25（Android Studio 自带的 JBR 就可以）、Android SDK build-tools 36.x、`platforms/android-35`。

```powershell
cd apk
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

产物在 `apk\out`。签名密钥第一次构建时自动生成，之后会一直复用。

## 原理

游戏把 `Engine.ini` 用 AES + HMAC 封了起来，密钥由 `libUE4.so` 里一段固定的 32 字节材料和本机 `UserGameplay.ini` 里的摘要一起算出来。

模块在游戏进程启动、Application 还没创建的时候插进去，用游戏自己的身份把配置解密、改掉档位、重新加密写回，然后回读校验，中途失败就回滚。安装包和账号数据都不碰。

## 已知限制

- 终极档有自己独立的资源表帧率上限，配置里写多少不代表实际跑多少
- 90 帧以上还需要系统向游戏上报足够的刷新率
- 阵亡镜头、设置界面那 30 帧是游戏自己锁的，改配置文件动不了
- 游戏更新如果换了 `libUE4.so` 的结构，模块会换一种方式去找认证材料，认证不过就直接拒绝写入

## 风险

改配置、用 LSPosed 都有可能被反作弊识别，封号的风险是真实存在的。项目按现状提供，不做任何担保，用不用自己判断。
