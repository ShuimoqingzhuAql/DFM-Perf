# DFM 画质工坊

《三角洲行动》国服的画质与帧率配置工具，LSPosed 模块，不需要 root。

装好模块，在 LSPosed 里勾选「三角洲行动」，打开 App 选好档位保存，重启游戏就生效。

**下载**：到 [Releases](../../releases) 拿最新 APK（当前 v2.8）。

## 能做什么

- 画质六档：流畅、标准、精致、高清、极致、终极
- 帧率六档：60、90、120、144、165、185
- 自定义渲染比例（进阶，默认关闭）：0–100%，带 100 / 90 / 80 / 70 四个预设
- 恢复默认：删掉工具写入的画质、帧率与渲染覆盖项，游戏下次启动重建
- 保存后可以直接启动游戏
- 自检：确认模块能读到本页保存的设置
- 隐藏桌面图标：隐藏后桌面不显示，在 LSPosed 模块页点右下角圆形按钮仍可进入
- 深色模式跟随系统

## 关于帧率：请用「极致」

靶场里「终极」可以跑到 185 帧，但大战场和实战对局会被压回 60 帧。原因是游戏的云端配置目前没有给「终极」画质开放高帧率机型，进入实战后会被按默认档位重新压回 60。

**想要高帧率，请选「极致」**——极致档不受这个限制，可以跑到屏幕刷新率上限。

App 里选到终极时会弹窗说明，可以一键切到极致，也可以选择不再提示；风险提示卡片里保留了「查看画质档位说明」，随时能翻回来看。

## 安装

1. 从 Releases 下载 `DFM-Perf-v2.8.apk` 并安装
2. 在 LSPosed 中启用本模块，**作用域只勾选「三角洲行动」**（`com.tencent.tmgp.dfm`）
3. 打开 App，首次进入会依次看到风险告知和「别忘了勾选作用域」提示
4. 选好画质和帧率，点「保存并下次启动生效」
5. 把游戏完全退出（最近任务划掉），再重新启动
6. 结果看 LSPosed 日志，标签 `DFMPerf`

游戏里改动画质或帧率只影响这一次，重启后会回到 App 里保存的档位。

## 从源码构建

需要 JDK 25（Android Studio 自带的 JBR 即可）、Android SDK build-tools 36.x、`platforms/android-35`。

```powershell
cd apk
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

产物在 `apk/out`。签名密钥第一次构建时自动生成，之后一直复用；要发布请换成自己的 keystore。

## 原理

游戏把 `Engine.ini` 用 AES + HMAC 封起来，密钥由 `libUE4.so` 里一段固定的 32 字节材料和本机 `UserGameplay.ini` 里的摘要共同派生。

模块在游戏进程启动、`Application` 创建之前插进去（`ActivityThread.handleBindApplication` 的 before hook），用游戏自己的身份把配置解密、改掉档位、重新加密写回，然后回读校验，失败就回滚。安装包和账号数据都不碰。

## 已知限制

- 终极档目前实战只能到 60 帧，见上文
- 90 帧以上还需要系统向游戏上报足够的刷新率
- 阵亡镜头、设置界面那些 30 帧是游戏自己锁的，改配置文件动不了
- 游戏更新如果换了 `libUE4.so` 的结构，模块会换一种方式找认证材料，认证不过直接拒绝写入

## 风险
